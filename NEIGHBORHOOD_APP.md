# NeighborHub - Verified Neighborhood Community App

A comprehensive mobile-first neighborhood community platform built with React, TypeScript, and Tailwind CSS.

## Overview

NeighborHub is a verified neighborhood community app that connects local residents through a safe, trusted platform. The app includes 13 major modules covering everything from authentication to community analytics.

## Features

### 1. **User Authentication & Profile Management**
- Login and Signup flows
- Profile management
- Settings and preferences

### 2. **Identity & Neighborhood Verification**
- Government ID upload
- Address proof verification
- Verification status tracking
- Verified member badges

### 3. **Neighborhood Creation & Management**
- Community-based organization
- Member management
- Location-based grouping

### 4. **Community Posts & Feed**
- Social feed with posts
- Categories (Lost & Found, Events, Questions, etc.)
- Like, comment, and share functionality
- Real-time community stats

### 5. **Announcements, Alerts & Notifications**
- Security alerts
- Lost & found notifications
- Event reminders
- Push notification system
- Priority-based alerts (urgent, warning, info)

### 6. **Events & Activities Management**
- Create and manage events
- RSVP system
- Event categories (Social, Community, Sports)
- Past and upcoming events tracking

### 7. **Local Services Directory**
- Verified service providers
- Service categories (Plumbing, Electrical, Cleaning, etc.)
- Ratings and reviews
- Contact and messaging
- Response time tracking

### 8. **Community Marketplace**
- Buy/sell items locally
- Product categories
- Condition tracking (New, Used, Like New)
- Distance-based listings
- Price and location filters

### 9. **Messaging & Communication**
- Direct messaging
- Group chats
- Online status indicators
- Unread message counters

### 10. **Trust, Rating & Reputation System**
- User ratings (1-5 stars)
- Review system
- Trust score calculation
- Achievement badges
- Context-based reviews (Service, Marketplace, Events)

### 11. **Moderation & Reporting System**
- Report inappropriate content
- Multiple report categories
- Confidential reporting
- Moderator dashboard

### 12. **Analytics & Community Insights** (Admin)
- Member growth tracking
- Activity charts
- Category distribution
- Issue reporting analytics
- Engagement metrics

## Design System

### Color Palette
- **Primary**: Indigo (#4f46e5)
- **Success**: Green (#10b981)
- **Warning**: Orange (#f59e0b)
- **Destructive**: Red (#ef4444)
- **Background**: Light Gray (#fafbfc)

### Key Design Principles
- Mobile-first responsive design
- Soft, rounded components (16px border radius)
- Friendly, approachable interface
- Clear visual hierarchy
- Accessible typography
- Gradient accents for visual appeal

## Navigation Structure

### Bottom Navigation Bar
- **Home**: Community feed and quick actions
- **Marketplace**: Local buy/sell platform
- **Services**: Directory of service providers
- **Messages**: Direct and group messaging
- **Profile**: User settings and account management

## Technical Stack

- **Framework**: React 18
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Routing**: React Router v7 (Data mode)
- **Charts**: Recharts
- **Icons**: Lucide React
- **UI Components**: Radix UI primitives
